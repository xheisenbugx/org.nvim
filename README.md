# org.nvim media

The GIFs and screenshots shown in the main README. They live on this
orphan branch instead of `dev`/`main` so that installing the plugin
doesn't download them.

They are recorded from the tapes and demo configs in
[`docs/media`](https://github.com/xheisenbugx/org.nvim/tree/dev/docs/media)
on `dev`; see the README there for how to re-record and publish them
(`make media`, then `make publish-media`).
