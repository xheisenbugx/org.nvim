Open this file with org.nvim installed. Keys below assume the default
prefix =<leader>o=; replace it with yours (for example =<leader>O=).
Press =g?= at any time to list every keymap.

* Visibility
Press =<Tab>= on a headline to cycle it (folded → children → subtree),
and =<S-Tab>= anywhere to cycle the whole buffer.
** A child headline
Folded text lives here.
*** A grandchild
Deeper still.

* Editing structure
- =<M-CR>= on a headline inserts a sibling; on a list item, a new item.
- =>>= / =<<= demote / promote this headline; =>s= / =<s= the subtree.
- =<M-j>= / =<M-k>= move a subtree (or list item, or table row).
- =<leader>ohy= copies a subtree, =<leader>ohp= pastes it.
- =<leader>o*= turns a line into a headline and back.
** Move me down with <M-j>
** Then move me up with <M-k>

* TODO Try TODO states                                                :work:

* Agenda and capture
- =<leader>oa= opens the agenda dispatcher. Try =a= (week), =t= (all TODOs),
  =m= with a match like =+work-home/!=.
- In the agenda: =t= changes state, =s= schedules, =I= clocks in,
  =<CR>= jumps to the entry.
- =<leader>oc= captures a new entry from any buffer.

Add this file to =agenda_files= to see its entries in the agenda.

* Tables
Type a =|= row and press =<C-c><C-c>= to align. In Insert mode, =<Tab>= moves
between fields. =<leader>oTf= recalculates the formulas.

| Item   | Qty | Price | Total |
|--------+-----+-------+-------|
| Apples |   3 |  0.50 |  1.50 |
| Pears  |   2 |  0.75 |  1.50 |
| Plums  |  10 |  0.20 |  2.00 |
|--------+-----+-------+-------|
| Sum    |  15 |       |  5.00 |

* Source blocks
Press =<C-c><C-c>= inside a block to run it, =<leader>o'= to edit it in a
real buffer with the right filetype.

#+NAME: greeting
#+begin_src lua
return "Hello from Neovim " .. tostring(vim.version())
#+end_src

#+begin_src sh :results output
echo "shell says hi"; date +%Y
#+end_src

#+begin_src python :var n=4
return [[i, i * i] for i in range(n)]
#+end_src
